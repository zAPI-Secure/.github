# zAPI-Secure

**Making forgotten APIs visible. Making API security smarter.**

APIs are an essential part of modern applications, but over time, some endpoints become forgotten, outdated, undocumented, or unused. These are often called *zombie APIs*, and they can create security risks when they remain accessible without proper oversight.

**zAPI-Secure** is an open-source initiative focused on addressing this overlooked aspect of API security. The vision is to help organizations discover zombie APIs, understand the risks they pose, and manage them safely before they become potential entry points for attackers.

Our goal is to make API security more proactive by reducing unnecessary exposure, improving visibility into API assets, and enabling safer, more accountable remediation.

## Our Vision

A world where organizations have better visibility into their APIs, forgotten endpoints do not remain hidden security risks, and remediation is both intelligent and controlled.

## What We Aim to Achieve

- **Discover** forgotten, outdated, and potentially exposed APIs.
- **Understand** the security risks associated with unmanaged endpoints.
- **Protect** applications by reducing unnecessary API exposure.
- **Remediate** identified risks through controlled and accountable actions.
- **Build Trust** through security, transparency, and verifiable outcomes.

## Why zAPI-Secure?

API security should extend beyond protecting the endpoints developers actively maintain. It should also account for the forgotten parts of an application that may remain exposed long after they are needed.

zAPI-Secure aims to bring this overlooked problem into focus and contribute to a safer API ecosystem through open research and community-driven development.

## Join the Journey

We welcome developers, security researchers, and open-source contributors who share an interest in API security and attack surface reduction.

**zAPI-Secure — Discover the forgotten. Secure what remains.**
